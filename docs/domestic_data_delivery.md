更新：2026-09-15（Asia/Shanghai）。本轮按用户要求，将 Wind 非 TLS 正式配置化，落实“跨电脑与发布”之前的国内数据接口、口径防护和有界稳定性检查。所有实现均在 ir_search 包内；桌面 BrokerSkills/skills 仅作只读参考。

### 不应消除的差异

1. **深市期权持仓冲突。** 90008034.SZ 在 2026-09-07 至 09-11 两家数值不同，尚无交易所原始文件裁决。请求持仓字段时返回 known_source_conflict、partial；不选赢家、不平均、不跨源补字段。该规则只覆盖已核实的这段冲突，不代表其他日期已逐日审核。
2. **财务币种。** JYDB 所用表没有币种字段。样本金额匹配不等于全库币种证明；默认 currency=null、partial。Wind 使用原有币种列。九项核心金额不代表财报全科目或完整更正历史。
3. **金额精度。** Wind 衍生品成交额独立乘 10000，不使用股票倍率。部分期货/期权与 JYDB 有差异，原值保留；不能承诺逐元一致。
4. **无成交记录。** 零成交的开高低零值转缺失；收盘原始值另保留 source_close，price_status 标记 no_trade_reference。结算不是成交价，允许结算在成交高低区间之外。
5. **日内量与窗口。** 三只股票各三天的 Sina 分钟成交量汇总，九组中四组与 Wind 日线相等，其余有差异，因此股票 Sina 仍只提供已接入的 OHLC。RB2610 在 09-14 的 69 根观察成交量合计 144087，对应 Wind 113657；SC2610 的 110 根为 223688，对应 Wind 324067。两者末根持仓和收盘均一致，但不足以确认全天量或计数口径。
6. **夜盘异常时间。** SC 样本存在来源标成 09-14 00:00 的一根数据，无法根据自然日和开市日可靠归属，trade_date 保持 null。没有为了对齐日线而改写时间戳。
7. **股指/商品期权日内。** AKShare 官方列有 Eastmoney 候选接口；本机一次有界请求返回 ProxyError，未获得有效样本，因此未注册该能力。ETF 期权仅当日点价，不能宣称支持最近数天历史。[官方说明](https://akshare.akfamily.xyz/data/option/option.html)

上述限制是调用结果的一部分。allow_partial=false 可拒收已识别的不完整数据；没有把“返回一些行”作为全面验收通过。

## 稳定性与边界

- 正式 Wind 接口以三个并发调用方完成六次只读请求，六次成功且已收盘数据完全一致；受账户约束的数据库操作在进程内串行。没有测试无限并发，也没有跨进程连接池承诺。
- 真实请求设置很短期限后返回 deadline_exceeded，取消请求返回 cancelled；两次之后的新请求均取回一行日线。无需重启服务。
- 离线故障注入验证阻塞 socket 读可中断、排队中取消不登录、连接最终释放、SDK 子进程被回收、下一次请求恢复，以及权限/限额/结构错误不自动换源。认证建立阶段仍受驱动连接超时粒度约束，不承诺毫秒级硬实时截止。
- 一次私有按日期排序寻找零成交的探索查询达到 25 秒期限，已终止；这不是公共接口查询方式。生产行情请求要求明确证券/合约和日期，避免全表扫描。零成交样本随后通过有界股票请求确认。
- 历史日内、PIT、连续合约、未声明复权、未知财务版本或字段明确拒绝，不合成替代数据。长时间在线可用率没有通过短时测试获得证明。

## 工程验证与隐私

全项目 `python3 -m pytest -q`：745 通过、6 跳过；五条既有 PDF 扩展弃用警告。跳过项不作为在线验收成功。本轮覆盖公共类、契约、投影、跨表分页、报告期/版本绑定、交易所编码、同码跨生命周期、零/空价格、负数异常、已知冲突、日历、非 TLS、超时及取消恢复。

带可选依赖的 Python 3.12 环境完成 86 项数据库、MCP、新数据接口及本地 wheel 回归；随后更新安装断言和 MCP 参数检查，再完成相关 35 项检查，范围有重叠，不相加计数。wheel 从无源码的无关目录加载 SDK/MCP、新模块和资源，未打包私有文件。这是本地安装回归，不是另一台电脑部署或 GitHub 发布。

实际凭证继续位于仓库根目录私有 credentials.env，权限 0600，受 Git 忽略；对 296 个 Git 候选文件检查本机敏感值，无匹配。公开模板无凭证。本轮未写入桌面 BrokerSkills/skills，运行时不导入 Desktop、个人绝对路径或 checkout-only 工具。

## 下一阶段边界

可以在保留上述 partial/unsupported 约束的前提下继续扩展；不能先把未解决来源问题的验收状态改绿。下一阶段依次考虑：基金数据 → 海外市场 → 宏观序列 → 网页/公众号 → 知识星球/IMA。

数值接口继续使用 get_data，先落实代码、币种、时区、复权、报告期/观测期与修订口径。素材接口复用 retrieve，返回来源、原文、稳定引用位置、发布日期、获取时间及权限/抓取诊断；搜索结果与原文引用分开，禁止把摘要当作原文。具体供应商、授权与字段在各接口开发时实测，不把预留 Key 当成已接入。
