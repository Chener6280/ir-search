# IMA 素材接入验收

日期：2026-09-16。使用本机私有 env 的官方 API Key / Client ID 做只读真实取数。正文、知识库清单、媒体 ID、签名下载地址及参考 skill 包均保存在 Git 忽略的本机 `.local/` 下；本报告只列汇总结果。

## 真实接口与内容

| 检查 | 结果 | 边界 |
|---|---|---|
| 官方认证及知识库目录 | HTTP 200、业务 code 0；第一页取得 20 个知识库，包含个人、共享、订阅类型 | 官方标记仍有后续页；不代表账户全目录 |
| 知识库关键词搜索 | 个人库取得 20 条候选，已覆盖 PDF、PPT、公众号等条目 | 当前 `search_knowledge` 实测有返回 `info_list` 而不返回分页状态；标记分页未知，不猜测已完结 |
| 个人笔记搜索 | 正文关键词搜索取得非空笔记，创建/修改时间按毫秒解析 | 这些时间不是原文发布日期 |
| 统一 SDK 搜索 | 单一个人库加笔记，候选预算 10，正文预算 2；输出 9 条匹配材料，2 份 PPT 正文、3 条仅元数据、4 条笔记摘要 | 返回 partial；搜索结果数量、读取预算和日期未知均显式保留 |
| PPTX 原文 | 两份分别提取 17,825 和 7,763 字符 | 文本提取不包含图片、图表和演讲者备注；未据此宣称完整解析所有演示内容 |
| `retrieve` 读回 PPT | 17,825 字符，10 条定位引用 | 文件原始出版者、标题和发布日期未从文件名猜测 |
| `retrieve` 读取 PDF | 11,392 字符，6 条定位引用，使用 PyMuPDF | 仅验证一份有文字层 PDF；不是 OCR 或所有 PDF 格式验收 |
| `retrieve` 读取本人笔记 | 976 字符，1 条定位引用 | 验证的是当前账号有权读取的笔记；共享笔记不可据此假定有权 |
| 字符引用一致性 | 上述返回的引用均与对应文本字符区间完全一致 | 不把引用存在当作材料内容已经被事实核验 |
| 真实 MCP 搜索 | `search_materials` 返回 2 条材料，正文读取预算 1 | 使用真实 FastMCP 工具协议入口，返回 partial 及有限扫描诊断 |
| 真实 MCP 读取 | `retrieve` 返回 1 份笔记正文及来源警告 | SDK/MCP 共用包内实现 |
| 无权读取条目 | 已观测知识库搜索成功，但正文接口业务码 220030 拒绝 | 映射 `entitlement_denied`，保留已取得的搜索信息；不伪装为“无内容” |

实测修正了两处官方协议差异：知识库目录使用 `kb_id/kb_name`；文件下载需要六个 `X-IMA-*` 临时认证头，其中 `X-IMA-Resource-Category` 允许为空。长期 API Key / Client ID 只发往固定官方 API 主机，临时下载认证限定于校验后的官方 IMA/Tencent COS HTTPS 域，不跟随认证重定向。
