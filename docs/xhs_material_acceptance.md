## 本机状态与跨电脑边界

本机已将 XHS 服务配置加入项目根目录的私有 `credentials.env`。第三方后端、登录会话及验收原始输出分别留在被 Git 忽略的 `.local/xhs-backend/`、`.local/xhs-backend/state/` 和 `.local/xhs-acceptance/`，缓存位于 `.local/xhs-cache/`。本次后端仅监听 `127.0.0.1:18060`；没有设置开机自启。重启电脑或后端退出后需要重新启动服务，登录失效时重新扫码。

其他电脑安装 `ir_search` 后，仍需自行安装兼容后端、设置本机服务令牌和完成登录。笔记内部引用不携带访问凭证；另一台电脑应先重新搜索以获得当地会话下的访问令牌。服务与缓存只针对一个本机账户，切换账户需轮换服务令牌并重新搜索。

当前不承诺博主全历史、穷尽评论、平台精确日期搜索、图片 OCR、视频转写或长期稳定性。社区反馈仍是未经独立核验的线索；是否能支持动销等结论，交由调用 skill 结合正式数据与其他原始证据判断。

配置、SDK/MCP 示例和缓存规则见 [小红书使用指南](xhs_material_adapter.md)。
