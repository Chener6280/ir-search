# Alpha派账号版素材验收

日期：2026-09-18。状态：**账号版共享会议 adapter 已实现，SDK 与安装包内 MCP 有限实取通过。** 生产来源名为 `alphapai`，仅在本机显式启用时注册；无需 Open API Key。

## 实际取数

通过 `search_materials` 查询“贵州茅台9月渠道动销”：发布日期 2026-09-01 至 2026-09-18，业务期间 2026-09-01 至 2026-09-30，文字查询“茅台”，证券条件由包内字典解析为 `600519.SH`，候选上限 5、详情上限 1。

|---|---|
| 手机号密码登录 | 新的包内浏览器 worker 登录成功，凭证来自私有 env |
| 目录读取 | 返回 4 条，日期、证券与计数可见 |
| 本地主题匹配 | 返回 2 组素材；其余候选不是被错误宣称为全部命中 |

字符数受本项目 HTML 清洗、换行和转录片段拼接方式影响，不应与供应商字数或前期评估的另一种文本清洗字符数直接比较。目录里的 `has_more=false` 只说明该次上游目录页的状态；整体搜索和文本完整性仍不声明为全覆盖。

成功请求的来源诊断包括 `alphapai_web_account_stored_materials`、`bounded_search_not_exhaustive`；retrieve 保留 `material_has_caveats` 及摘要非原话、转录不完整、时间单位未核实等具体警告。没有把这些警告隐藏为完全成功。

## 实测中修复的问题

1. 参考技能的纯日期会触发业务码 `500000`。现已按完整起止时间传参，并再次按返回发布元数据过滤。
2. 搜索标题包含高亮标签。现已按标签内实际文字规范化，避免拆出多余换行后与详情标题不一致。
3. ID 不仅随搜索变化，在列表和详情响应之间也会重新编码。现将详情绑定到实际请求引用，搜索阶段核对标题及发布日期，缓存按请求引用隔离；不能再要求两个加密 ID 字符串相等。
4. `mtSummary.content` 为 JSON 字符串。本版解析片段和原始时间字段，不把序列化 JSON 当作正文，不以 AI 摘要代替缺失转录。

- 新增测试覆盖配置和凭证脱敏、只读接口白名单、业务错误/配额、ID 轮换、日期边界、分页重复与预算、摘要与转录分层、引用偏移、缓存篡改/账号隔离/过期/权限、浏览器生命周期和 MCP 路由。
- wheel 从临时构建目录生成；检查必要模块和资源均入包，源码不包含开发者绝对路径，私有 env、缓存、账号文件及本地参考库未入包，未包含本地凭证值。
- 在与源码无关的目录使用 `python -I` 和已安装包验证：12 个 MCP 工具可用，`source_health` / `list_capabilities` 不发网络请求，真实搜索和缓存读取通过，未导入 `ir_search.research`。

本轮验证用的浏览器环境为 Python 3.12 + Playwright 1.63.0；浏览器可执行文件由本机私有配置指定。其他电脑应在运行 SDK/MCP 的 Python 环境安装可选浏览器依赖和对应 Chromium，不应照抄本机路径。

本地详细诊断和构建校验记录保存在 Git 忽略的 `.local/alphapai-acceptance`；不发布取数账户、密码、会话或私人转记目录。原始 BrokerSkills 只读保留，参考库已标记实际迁移内容。

## 保留边界

本轮未启用官方 Key 检索、私人录音、音频下载或生成接口。两次有界搜索和一次旧引用读取不能证明全市场历史覆盖、长期可用性、引用永久有效或全文权限。每日详情额度与计费仍未知；验证码、认证过期和额度错误会明确停止。机器转录只覆盖供应商此次返回的片段，时间单位仍未正式核实。
