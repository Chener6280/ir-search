## 确定性测试

基础环境执行 `python3 -m pytest -q`：**1,457 passed，15 skipped**，5 条既有 PDF/SWIG 依赖警告。跳过项涉及未安装的可选依赖/特定运行环境；在 Python 3.12 的验收环境中，平台、MCP 和独立安装相关选集 **72 passed**。

新增平台测试在安装 YouTube/MCP 可选依赖的环境中通过，覆盖：

- 详情 URL 规范化、分 P、BV/av、YouTube 分享/短视频/直播链接与伪域名拒绝。
- 来源开关、国内博查/海外 AnySearch 固定路由、共享候选/读取预算、离线预览、单平台失败隔离、日期与中国时区。
- 主帖正文与来源行、作者、日期；评论与导航排除；验证页、错帖 ID 和无正文拒绝。
- Cookie 的固定域名边界、跨域重定向拒绝及上游回显保护。
- Bilibili 字幕字段、语言选择、自动字幕标记、字数截断、字幕字符位置与时间引用。
- YouTube 第三方库的真实调用协议以合成网络响应验证：页面 → 只读 player → timedtext，全部经过本项目的有界传输；无需实际网络，也不是实际字幕验收。
- 元数据与字幕都失败时不返回成功材料；仅元数据时无正文证据；MCP 参数及 JSON 输出验证。
