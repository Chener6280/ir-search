# 知识星球素材接入验收

日期：2026-09-15。范围为本机已授权账户、官方 MCP、有预算的只读操作。实现以华福 skill 的投研取材流程为参考，在 `ir_search` 内独立重构；桌面参考文件没有改动。私人账户、星球清单、响应全文、签名链接与凭证不随项目发布。

## 官方接入与实际范围

- 固定 HTTPS MCP 接入完成初始化、JSON/SSE 处理及会话协商，实际读取账户资料与星球目录成功。
- 一次目录请求返回 50 个星球；不据此认定账户星球已完整列出。
- 本机按名称中“投研 / 调研 / 研报 / 纪要”筛出 11 个作为初始私有配置，按目录顺序保留。每次只读取前 3 个，没有自动轮换或全历史扫描；调整顺序和范围使用私有 env。
- 官方工具目录仅用于本地核对，运行实现不会自动开放新发现的工具。官方 RAG `search_topics` 未进入搜索热路径。

引用逐项对照返回版本的标题、文本或对应附件名切片。上述 SDK 与 MCP 样本可能重叠，不能相加作为独立材料数。附件元数据数也不等于已读 PDF 数。

搜索实际使用“公司 / 行业 / 研究 / AI / 数据 / China / Global”等词验证取材链路，没有宣称“贵州茅台 9 月动销数据”已找到或已核验。第三个星球所取记录早于指定日期窗口，明确剔除并保留 `community_outside_publication_window`；返回游标和 `has_more` 表明历史内容尚未穷尽。

PDF 首次验收因专用验收环境缺少 PyMuPDF 返回 `dependency_missing`；安装可选提取依赖后，针对同一已选文件重试成功。运行代码也会在索取签名下载链接前检查依赖。PDF 发布日期和原始发布方仍未确认，因此最终状态为 `partial`，而不是无条件成功。

## 不应视为已经验收的部分

- 真实问答样本是官方简化格式，未返回分开的问答正文；被提问人不当作回答作者。保留 `source_excerpt`、`unverified` 角色及专门诊断。明确问答分段仅通过合成测试。
- 评论接口曾成功返回空列表；非空真实评论、楼中楼和完整评论历史尚未验收。默认评论关闭；已测的角色分段与预算行为使用合成数据。
- 未验收所有星球、历史内容召回率、所有文件类型、扫描 PDF 的 OCR 或每个研究行业。默认只查前 3 个配置星球，不能把无命中解释为该账户全库无材料。
- 当前没有持久化索引、公共续取游标参数、自动跨批次同步、官方 RAG 融合、生成摘要或研究结论。旧 CLI 搜索和旧 `deep_research` 保留原有兼容行为。
- 这是本地验收；尚未在另一台实体电脑部署，也未在本轮提交或推送 GitHub。
