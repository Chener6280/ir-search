## 空结果与协议问题

- 首轮近期公告、研报、问答样本均为空；这只描述所选公司/日期窗口，不代表接口无权限或整个类别没有近期数据。
- 首轮政策误用 `YYYYMMDD` 得到空数组；改成官方要求的完整日期时间后，相同日期得到 2 条。这说明参数格式错误可能表现为 HTTP 200、`isError=false`、`[]`，正式 adapter 必须自行严格校验日期格式。
- 新浪财经 2025-08-26 09:00:00–10:00:00 样本为空，近期同长度窗口非空；未用重复扩大查询推定完整历史。
- 首次工具目录响应约 277 KB，单个 SSE data 行超过临时探针的 64 KB 单行读取限制，造成一次本地解析失败。修正探针后，第二次目录读取成功；不是账号认证失败。正式客户端应采用标准 MCP transport，设置整体响应上限并测试长 SSE 事件。
- 本轮没有发生服务端返回的明确认证/权限错误。不能从“未遇到错误”反推未测试端点全部有权。
