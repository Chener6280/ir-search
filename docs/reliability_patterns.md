# 已审阅的来源故障模式

此文件是维护参考，不是从网页自动提取的运行指令。运行中只使用包内 `infrastructure/recovery.py` 的固定规则。修订规则时先补可重复的测试，再检查来源与凭证边界。

| 模式 | 已确认的影响 | 已采用处理 | 回归依据 |
| --- | --- | --- | --- |
| 配置存在但运行环境缺依赖 | 仅检查 env 会把不同 Python 环境混为一谈 | doctor 分开列配置、依赖、探测范围；输出可选安装项 | `test_source_diagnostics.py`：依赖缺失、可选依赖不阻断主路径、登录不冒充正文验收 |
| 小红书登录成功但页面等待超时 | 本项目上一轮真实搜索/详情出现过 `context deadline exceeded` | 诊断为 timeout；保留有限结果，调用方决定下次请求 | `test_xhs_transport.py`：安全错误映射；本地 XHS 验收记录 |
| 公众号/IMA 下一页中断 | 原续取位置在提前返回前未写入，调用方丢失继续线索 | 提前返回前保留上一个有效位置，停止该来源的后续请求 | `test_material_runs.py`：公众号受限续取、IMA 中断续取 |
| 星球详情中途限流 | 候选批次预先计数，可能跳过未检查的帖子 | 按实际检查数更新扫描和续取 | `test_material_runs.py`：星球限流后余下帖子可取得 |
| 集合权限与账户认证混同 | 一个无权星球不应隐藏另一个已授权星球 | 资源级权限缺口局限当前集合；账户级失败停止来源 | `test_zsxq_materials.py`：单组失败仍能读取其他已授权组 |
| 长查询产生较长游标 | 合法游标被普通字符串上限拒绝 | 游标独立长度上限与结构校验 | `test_material_runs.py`：超过 2,000 字符的合法游标 |
| 任意异常/素材落入日志 | 可能持久化账号、搜索内容或凭证 | 字段白名单，未知代码归并，私有权限，禁止原始异常 | `test_source_diagnostics.py`、`test_material_runs.py`：错误脱敏、私有记录、篡改与符号链接 |
| 全局返回上限之后直接续取 | 已匹配但未返回的项可能漏掉 | 辅助函数拒绝，要求先调整本页预算 | `test_material_runs.py`：结果截断时拒绝自动生成续取请求 |

合成回归证明对应分支行为，不证明平台永远可用；真实验收也不替代这些边界测试。新的经验应附可观察证据、影响范围、拟改规则和验证结果，不把转载次数、单次成功或模型判断当作事实验证。
