# FMP 海外数据接入准备

用户当前使用 FMP 免费套餐，计划项目落地后再升级。本机私有 credentials.env 中的 FMP_API_KEY 已填写；2026-09-15 已完成首轮五次真实请求，全部成功，覆盖 AAPL 公司资料、日终点价与成交量、2024/2025 财年三表。详见[免费套餐验收结果](fmp_free_acceptance.md)。此后已完成正式 adapter，注册到 SDK/MCP；新增一轮五次请求验收覆盖五年三表，见[接口指南](fmp_adapter.md)和[正式验收](fmp_adapter_acceptance.md)。公开模板中的 Key 保持空值。

首轮账号探测按以下边界执行；下面记录的是当时的五次请求预算，与后续正式 adapter 验收分别计数：

- 首轮最多五次串行请求，不批量扫描或后台轮询，不对权限/配额错误重复请求。
- 使用 FMP 官方 Stable API，先核实认证和公司资料，再检测少量日终行情及财务接口的实际权限。免费套餐不可用的字段或标的保留权限诊断，不当作空数据。
- 记录字段、币种、日期、实际行数与来源；先确认价格复权及财务期间口径，再注册公共数据能力。
- Key 只在本地读取；日志、报告和异常不输出 Key、带 apikey 的 URL 或原始认证错误。
- 未来升级后重新探测权限并扩大能力，不把本地套餐标签当成授权证明，也不承诺免费测试能验收全部海外市场。

官方价格页当前列明 Basic 免费套餐每天 250 次请求，包含日终历史及公司资料/参考数据，但接口和标的权限仍须按实际账号检测。五次上限是本项目首轮测试预算，不是目前已部署的全局限流器。[FMP 官方套餐说明](https://site.financialmodelingprep.com/pricing-plans)

接口选择以 [FMP 官方文档](https://site.financialmodelingprep.com/developer/docs)为准。长期日内仍遵循原项目约定，本阶段不新增历史日内来源。
