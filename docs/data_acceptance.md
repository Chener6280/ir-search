## 可经 SDK/MCP 调用的真实样本

通过 `get_data` 对同一历史区间做两次串行读取，比较返回记录的 SHA-256，不将抓取时间混入比较。样本日期为 2026-09-11；默认日期选择器只取前一个工作日，不代替交易所节假日日历。

| 入口/来源 | 样本 | 每次行数 | 结果与边界 |
|---|---|---:|---|
| Wind A 股日线 | 沪深主板、科创板 | 0 | 端点不支持 TLS；认证前拦截，未发送明文密码 |
| JYDB A 股 OHLC | 600519.SH、000001.SZ、688981.SH | 3 | 两次一致；已走普通表/科创板分表 |
| JYDB 成交量/成交额 | 600519.SH | 1 | 两次一致；单位按字典为股/人民币元 |
| AKShare 新浪 A 股 1m | 600519.SH | 238 | 两次一致；只开放 OHLC，未证明全交易时段齐全 |
| AKShare 新浪 A 股 1m | 000001.SZ | 238 | 两次一致；只开放 OHLC |
| AKShare 新浪期货 5m | IF2609 | 48 | 两次一致；保留原生报价和自然日期 |
| AKShare 新浪期货 5m | RB2609 | 13 | 两次一致；样本稀疏，不作为完整时段证明 |

上述首次验收共 6 个统一接口样本获得数据且重复一致。另对 JYDB 上述三只股票 2026-09-07 至 09-11 的 15 行进行成交额/成交量比值检验，15/15 位于当日高低价区间（容差 0.01 元/股）。后续通过用户授权的 Wind 非 TLS 验证完成了双源逐值对账，结果见前述报告；不代表默认 TLS 连接已可用。

AKShare 东方财富接口本轮实取返回 `network`；新浪接口可用。本机私有 env 已明确选择 `AKSHARE_STOCK_BACKEND=sina`，不是无提示地替换来源。公开模板保留 `eastmoney` 默认值。新浪的成交量/成交额单位尚未独立验证，因此 capability 中不开放这两个字段；调用方须按 `list_capabilities` 显式选择支持的字段。

所有上述行情均标注 `data_vendor`、`data_table`、`live`。`source_tier=null` 表示本项目针对官方公告的来源等级不直接套用于商业行情表，不代表交易所原始数据。日内统一返回 `partial`；`complete` 只描述这一页，不证明上市期间全覆盖、交易时段齐全或无延迟。

期权探测发现两个影响稳定性的实际问题：

1. 仅按日期扫描 `Opt_DailyQuote` 达到 8 秒查询上限，返回 MySQL 3024。先限定合约内部编码，再限定日期，ETF/股指期权样本约 0.04 秒返回。正式 adapter 应要求具体合约或先完成有界的合约解析。
2. 已结束交易的合约在目标日期为空，不能判定为来源无此品类。按上市日、最后交易日筛选仍存续的商品期权后，获得有效行情。

上述样本不证明北交所、所有交易所、所有期权品种、退市合约、历史修订版本均已覆盖。不能把“某张表存在”或“某次读取有一行”当作全品类支持。

## 已落实的口径和稳定性约束

- 统一入口拒绝高低价倒置、开收盘超出区间、A 股负价格、负成交量/成交额，以及重复主键、越界日期和非有限数字。
- 数据库 A 股 OHLC 的零值转为缺失并附诊断，兼容停牌行；零成交量保留。缺失不会补成虚构价格。
- 新增 `futures_intraday`。`bar_time` 带上海时区；`calendar_date` 是自然日期；`trade_date=null`，不推算夜盘归属。`start/end` 按自然日期过滤。
- 期货报价使用合约原生单位；`source_volume` 和 `source_open_interest` 保留原始计数并标注口径未验证。不能当成股数，也不能直接据此计算名义敞口或收益。
- 本地字典显示大商所部分成交/持仓统计自 2020-01-01 从双边切换为单边。历史 adapter 必须保留该口径断点，不应无说明地拼接。
- 财务映射还需区分合并/母公司、原始/调整、累计/单季、报告期/公告日、报表币种和供应商存储单位。数据库快照不承诺历史时点可得性（PIT）。
- 只读、参数化、有行数与时间上限，连接串行使用并关闭。SDK 调用在可终止的独立进程运行，凭证环境变量不传给 SDK，第三方日志不进入 MCP 输出。
- 验收遇到认证、TLS、限额等终止性错误会停止对该 provider 后续探测，不连续重试。短时重复结果一致不等于长期可用率证明。

## 凭证与 Wind 阻塞

本机凭证集中在仓库根目录 `credentials.env`，权限 0600，受 Git 忽略。Wind 由本地已有共享配置迁入，JYDB 使用用户补填的凭证。JYDB 验证用 CA 的本地副本保存在 `.local/jydb-ca.pem`；校验证书指纹与信任链。`.local/` 同样不进入 Git 或安装包。

公开模板和代码不含凭证，也不会自动读取桌面技能或系统钥匙串。换电脑时配置该电脑自己的 env 和 CA 路径即可。

常规 Wind TLS 连接返回 `tls_not_supported`。默认政策仍然禁止把 TLS/权限/网络故障伪装成“没有数据”后自动切换；默认 Wind 优先的调用仍会失败。可显式选择 `provider="jydb"` 使用已验证的 A 股日线。后续经用户授权的非 TLS 专门验证已成功，成交量/额换算参数也已核验并写回本机 env；正式默认连接方式未修改。未来可配置受验证的 TLS 端点，或明确接入用户选择的非 TLS 模式，不进行无提示降级。

## 可重复运行

安装可选依赖 `.[mysql,akshare]`，并通过 `IR_SEARCH_CREDENTIALS_FILE` 指向本机私有配置：

```bash
# 不访问网络，只列出覆盖与计划
python -m ir_search.acceptance

# 显式真实只读取数；输出文件必须尚不存在
python -m ir_search.acceptance --live --output .local/acceptance-new.json
```

安装包也提供 `ir-search-acceptance`。CLI 默认离线；成功生成报告不表示数据通过。退出码 2 表示真实样本检查尚未全部通过，1 表示运行或写入失败。`sample_checks_passed` 仅用于本次样本与重复性，`full_acceptance_passed` 不会由小样本自动置为 true。

Python 可以用 `AcceptanceProbe` 与 `run_data_acceptance` 指定有代表性的真实证券、合约、日期、字段。每次最多 30 个探测，每个最多重复 3 次，默认全程预算 180 秒；没有后台轮询或监控任务。报告仅保留行数、覆盖、诊断、耗时和样本摘要，不保留记录正文或凭证。

SDK 示例：

```python
from ir_search import DataRequest, get_data

daily = get_data(DataRequest(
    "prices_daily", symbols=["600519.SH"],
    start="2026-09-07", end="2026-09-11", provider="jydb",
)).to_dict()

# 日期须位于实际运行当天的最近 14 个自然日内。
bars = get_data(DataRequest(
    "prices_intraday", symbols=["600519.SH"], fields=["open", "high", "low", "close"],
    start="2026-09-11", end="2026-09-11", frequency="1m",
)).to_dict()
```
