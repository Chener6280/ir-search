九个文本列表接口各取最多 2 条真实样本，均成功返回标题、来源 ID 和带时区的发表时间：投行研报、公司研究、资管报告、公开文献、电话会、资讯流、市场日报、研究文章、Mikko 日志。独立图表列表亦完成接口格式勘察，但没有纳入本轮 adapter 的可调用范围，不能把此项描述为已经提供图表检索或数值提取。

另对九类列表各执行一次限定窗口的不存在关键词查询，确认真实空结果格式。公开文献与电话会使用各自特有的空结果文字，已纳入解析及回归测试；异常文本仍按接口结构错误处理，不当作空结果。

本地已开启 `WISBURG_MATERIALS_ENABLED=true`，保留原 Key 字段名；每次搜索默认最多 20 个业务调用、每栏最多 1 页。没有输出 Key、账户余额或完整付费正文；私有原始响应和验收 JSON 均位于 `.local/`，不进入 Git/wheel。

关键词检索的边界也已实际观察：`article` 栏使用“美联储”，候选上限 2、详情读取上限 1 时，上游检索成功返回 2 条候选，但本地词匹配没有保留结果。返回 `source_scan_incomplete` 和 `no_match_in_scanned_records`，没有鉴权或网络失败。改用已知文章标题词 `Mikko` 后检索和正文读取成功。供应商相关性搜索不保证有限返回文本中出现相同字面词；调用方应明确关键词、候选和正文预算，不能把小样本无命中解释为没有相关材料。

本轮同时修正同等相关性下摘要与仅标题结果的排序：已取得摘要的条目优先于仅有元数据的条目，避免详情读取成果被结果条数限制挤出；排序分值不代表事实核验等级。
