# 网页地区路由验收

日期：2026-09-16。目标：`search_materials` 的网页来源在国内使用博查、海外使用 AnySearch，凭证集中于本机私有 env，支持 SDK/MCP 和独立安装。

## 已交付行为

- 新增 `BochaWebClient`，与 AnySearch 共用有界公开 HTTP 传输，但固定端点、请求结构和凭证分别处理。
- `WEB_SEARCH_PROVIDER=regional` 开启国内博查 / 海外 AnySearch；`web_region=cn/overseas/both/auto` 可由 skill 显式传入，自动识别及语言默认值均有依据诊断。
- 跨地区最多各查一次，两家共享总计至多 10 条候选以及正文读取预算，原站读取继续校验地址、TLS、内容大小与引用。
- 每条结果保存实际 `discovery_provider`；每路扫描披露地区、选择依据、状态、接收/检查数量。单家失败保留另一家结果；全部子查询失败返回 `unavailable`，不作为成功空查询。
- 同一 URL 被两家发现时归组并保留两家的版本记录，不解释为独立佐证。专项测试发现并修复了旧候选校验拒绝这种重复 URL 的问题。
- 本机将 `ir_search.env` 中已有的两家 Key 复制到 `credentials.env`，启用地区路由、关闭匿名，其他凭证保持不变。代码不执行旧 env，也不在运行时依赖私人迁移脚本。

## 有限真实取数

三次调用均使用现有 Key 和官方固定 HTTPS 接口，不创建账户或替换凭证。日期窗口均为 2026-01-01 至 2026-09-16。

| 调用 | 实际搜索 | 最终返回 | 引用核对 |
|---|---|---|---|
| SDK 国内：政府工作报告、人工智能 | 博查返回/检查 4 条；原站读取预算 2 | 3 条材料：1 条提取文本、2 条搜索摘要 | 6 处：3 处正文、1 处摘要、2 处标题 |
| SDK 海外：NVIDIA 季度业绩 | AnySearch 返回/检查 4 条；原站读取预算 2 | 4 条材料：2 条提取文本、2 条搜索摘要 | 10 处：6 处正文、2 处摘要、2 处标题 |
| 真实 FastMCP：中美人工智能政策，`web_region=auto` | 自动选择两家，各返回/检查 2 条；共享正文读取预算 2 | 2 条 AnySearch 搜索摘要；博查结果在日期核对后未保留 | 4 处：2 处摘要、2 处标题 |

全部 20 处引用逐项对照返回版本的标题或文本字符区间及 `version_id`。这些包含正文、摘要和标题，不能统称原文引用。SDK 与 MCP 的材料可能重叠，不能据此累计独立来源数。

实际读取的正文包含 `changwu.gov.cn` 的 515 字符页面、`nvidianews.nvidia.com` 的 12,000 字符截断文本和 `investor.nvidia.com` 的 4,399 字符页面。这证明搜索与有界原站提取可用，不证明相关经营指标已核验，也不保证完整复原页面。

## 真实出现的限制

- 国内和跨市场样本出现原站 TLS 校验失败，保留 `tls_error` 与读取失败标记；未关闭证书验证、未将摘要升级为正文。该失败发生在候选原站，不是搜索 API 的 Key 验证失败。
- 已知发布日期越界的材料明确剔除。海外样本的 4 条返回材料没有可确认的发布日期，均保留日期未知标记；其中一条正文达到 12,000 字符上限，明确截断。不能将它们视为已确认落在指定日期窗口内。
- 跨市场 MCP 样本最终只有搜索摘要，不能据此宣称该次调用取得了正文。两条扫描记录证明两家确实被调用；最终返回数与实际扫描数分开。
- 自动地区识别是有限规则，不是完整市场分类器。已知范围的 skills 应显式指定地区。搜索引擎的选择不强制限定结果的网站国别或内容市场。
- 旧 `search` / `deep_research` 兼容链路未接入新的地区编排。本轮没有发布 GitHub，也未验证另一台实体电脑的网络或账户条件。

- wheel 从无源码的无关目录、禁网络环境运行 SDK/MCP 合成用例；检查新增地区路由模块与博查客户端、资源加载、配置诊断及私有文件排除。
- 凭证检查只输出状态和计数，不输出真实 Key；公开模板保留空值，验收响应保存在 Git 忽略的本机私有目录。
