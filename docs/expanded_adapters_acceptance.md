## 故障与约束验证

- 无凭证泄露、只读 SQL、精确份额类别与交易所映射；原始 / 累计 / 复权净值不互填。
- 基金分页签名、跨请求游标拒绝、重复源记录拒绝、份额与持仓单位、零报价与异常 OHLC 校验。
- 宏观错序列/错国家/错币种/倍率、CSV 验证页、非有限数、重复观察期、缺值、截断与多序列部分失败。
- Fiona 单对象与列表两种结构、合约元数据、交易所/存续期、旧分钟请求拒绝、夜盘交易日、原生风险参数、数量冲突、预算/超时和 Bearer 传输既有测试。
- 港交所索引代码与日期不匹配拒绝、恶意外域链接拒绝、未知发行人缺口、目录与正文分离、日期过滤、真实原文引用、零网络预览。
- 非港股请求不调度 HKEX / 公司 IR，避免消耗其他素材源预算。未将新能力自动接入 `deep_research`。
