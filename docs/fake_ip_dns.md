# 假 IP 解析与公共网页读取

公共网页读取会拒绝内网、回环、链路本地与假 IP，并固定使用检查过的数字地址建立连接，保留原始 TLS 主机名。代理软件返回假 IP 时，这个防 SSRF 检查可能使本可访问的公开页面返回 `blocked_url`。不能以放行假 IP 或删除安全校验修复。

可在本机 `credentials.env` 设置以下非秘密参数，默认不启用：

```text
PUBLIC_WEB_REAL_DNS_HOSTS=money.163.com,www.sse.com.cn
PUBLIC_WEB_REAL_DNS_PROXY=http://127.0.0.1:7897
```

清单仅按精确主机匹配，不匹配子域或通配符。仅当系统全部答案在 `198.18.0.0/15` 假 IP 范围内时，对清单内主机经指定本机 HTTP 代理向固定加密 DNS 请求真实 A 记录；不继承代理环境或认证，不跟随 DNS 请求重定向，不缓存答案或在失败时使用旧结果。所有答案仍必须是公网地址、属于查询名称/CNAME 链且在原有效期内；混合内网答案也拒绝。

实际网页仍走原地址固定及 TLS 校验流程，由系统网络保护决定直连或代理。这个设置不向系统写 DNS，不更改代理软件规则，也不证明网页请求的出口身份或 Guard 首次验收。

未登记主机、解析失败、TTL 已过期、不安全答案继续返回失败；不能为了可用性扩大为全网站豁免。重定向后的新主机单独校验。现有长期运行的 MCP/SDK 进程需正常重新载入模块后使用新代码，安装补丁不代表已重启全部会话。
